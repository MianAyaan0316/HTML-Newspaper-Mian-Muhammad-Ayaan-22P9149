## Project Description
This project recreates the front page of Nawa-i-Waqt dated December 16, 1971 — the historic day Indian forces entered Dhaka. The page was rebuilt using only HTML with inline styles, using tables for the multi-column newspaper layout. All text was translated from Urdu and rephrased in my own words.

## Features Implemented
- 3-column table layout for the main newspaper section
- 2-column table layout for the war photo section
- Semantic HTML5 tags: header, article, section, footer, nav, figure, figcaption
- Proper heading hierarchy: h1, h2, h3, h4
- Unordered list for Enemy Losses section
- All images have alt attributes
- HTML comments on every major section
- Inline styles only — no external CSS or JavaScript

## Challenges Faced
Creating a multi-column newspaper layout using only HTML tables without any CSS framework was the main challenge. I solved this by setting percentage widths on each table column and using inline border styles to simulate the column divider lines of a real newspaper.
